**Table S18** (`Source_data/Table_S18.csv`)

Table S18. Independent cohorts and datasets used for external validation. Overview of the independent cohorts and datasets used for external validation across the molecular layers investigated in this study. The table summarizes the molecular layer, tissue or biological compartment, corresponding study reference (PMID), dataset access link, external phenotype or comparison used for validation, and the purpose of each analysis. Liver transcriptomic signatures were evaluated in GSE162694 and GSE135251, serum polar metabolomic signatures were evaluated in EPoS cohort (ST001711), and liver lipidomic signatures were evaluated in ST000915. External validation contrasts were defined according to the phenotype classifications and metadata available in each dataset.
