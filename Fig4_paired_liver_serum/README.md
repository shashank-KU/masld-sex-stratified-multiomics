# Source_data for Fig. 4: paired liver-serum analysis

First row of each CSV = column headers (caption removed; captions below).

**Table S10b** (`Source_data/Table_S10b.csv`)

Table S10b. Paired liver–serum metabolic comparison (n = 187). Restricted to participants with matched hepatic and serum polar metabolomics, and to the 40 metabolites annotated and present exactly once on both platforms. Hepatic and serum effects are from separate limma models fitted on the full feature set of each compartment (adjusted for age, BMI and sex) and then restricted to the matched panel; FDR ≤ 0.10 throughout. The primary discordance model is the phenotype effect on the within-subject difference (liver minus serum) after z-scoring each metabolite within compartment. Positive values of the difference indicate that the association with histology is more positive in liver than in serum; they do not indicate a higher absolute level in liver. Two sensitivity models are reported: an unmoderated ordinary least-squares fit on the same difference, and a stacked mixed model using limma's duplicateCorrelation blocked on participant. Summary statistics (sign tests of opposite liver–serum directions) are given below the metabolite-level table; shaded rows indicate metabolites discordant at FDR ≤ 0.10. Table S10a reports serum associations in all participants with serum profiling (n = 209); the smaller number of significant serum metabolites here reflects the reduced sample size of the matched subset, not a different dataset. For example, glutamic acid reaches FDR = 0.012 in Table S10a and FDR = 0.060 in the matched subset.

**Table S11** (`Source_data/Table_S11.csv`)

Table S11. Robustness of the paired liver–serum comparison (n = 187). (a) Number of histology-associated hepatic (of 701) and serum (of 653) polar features (limma, FDR ≤ 0.10), and number of the 40 matched metabolites with a significant liver–serum difference (FDR ≤ 0.10). Results are shown under the base model (age, sex, BMI) and after further adjustment for the hepatic triglyceride (TG) index; the sample dilution factor; probabilistic quotient normalization (PQN); HbA1c and fasting glucose; or the TG index together with HbA1c and glucose. Steatosis grade was added to every model for the inflammation analyses only. The TG index and the dilution factor are defined in the Supplementary methods. Excl. lipid-like removes hepatic features correlated with the TG index (|ρ| > 0.5), and key-6 denotes the six amino acids discordant for inflammation in the base model. (b) Standardized effect sizes (SMD) and partial R² of the 40 matched metabolites. A summary for each compartment (median |SMD|, number of metabolites with |SMD| > 0.3, median partial R², and a paired Wilcoxon test of |SMD| between compartments) is followed by the values for each metabolite. (c) Liver, serum and paired estimates for the 12 matched amino acids under each model. The paired estimate is the phenotype effect on the within-subject liver-minus-serum difference, computed after each metabolite was z-scored within its compartment, so it does not equal the difference between the liver and serum columns. (d) Cross-validated discrimination (elastic net, 10 × 5-fold) of steatosis, lobular inflammation, MASH and any fibrosis (F1–F4 versus F0). The predictor sets are clinical variables alone (age, sex, BMI, HbA1c, glucose); serum or hepatic metabolites alone, using either the 40 matched metabolites or all features of that compartment; and clinical variables plus serum or hepatic metabolites. Values are mean AUC (range across the 10 repeats). (e) Paired AUC comparisons (DeLong test on out-of-fold predictions averaged over repeats). Repeats favoring first is the number of repeats (of 10) in which the first predictor set had the higher AUC. It shows how stable the result is across cross-validation repeats and is not a test of statistical significance. SMD, standardized mean difference; AUC, area under the ROC curve; FDR, Benjamini–Hochberg false discovery rate.
