# Tables for Supplementary: EPoS serum validation

First row of each CSV = column headers (caption removed; captions below).

**Table S19** (`Source_data/Table_S19.csv`)

Table S19. EPoS cohort (ST001711) serum metabolomics validation summary. Summary of external serum metabolomics validation in the independent EPoS cohort using phenotype-specific external contrasts: grade 1 versus grades 2–3 for steatosis, grade 1 versus grades 2–3 for inflammation, and stage 1 versus stages 2–4 for fibrosis. The table reports the number of discovery-significant metabolites, externally significant metabolites, discovery features measured in EPoS, directional concordance, and the number of features not represented in the external panel. Directional concordance was assessed independently of external statistical significance.

**Table S20** (`Source_data/Table_S20.csv`)

Table S20. Feature-level EPoS serum (ST001711) metabolomics validation. Complete feature-level comparison of discovery-stage serum metabolite associations with the corresponding EPoS serum metabolomics measurements. The table identifies matched and unmatched discovery-significant metabolites and provides discovery and external effect estimates, significance measures, and direction of association for matched features.
