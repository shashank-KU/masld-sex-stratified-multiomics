# Tables for Fig. 2: serum metabolome

First row of each CSV = column headers (caption removed; captions below).

**Table S10a** (`Source_data/Table_S10a.csv`)

Table S10a. Differential serum metabolites associated with steatosis and inflammation. Serum polar metabolomic profiling in all participants with serum data identified 16 associations (12 with steatosis, 4 with lobular inflammation; 13 unique metabolites) at FDR ≤ 0.10. Columns give the metabolite name, histological phenotype, log2 fold change (logFC), average abundance (AveExpr), moderated t-statistic (t), raw p-value (P.Value), FDR-adjusted p-value (adj.P.Val), direction of change (Up = increased, Down = decreased), m/z and retention time. Unannotated features are labeled "UNKNOWN_" with a unique identifier.
